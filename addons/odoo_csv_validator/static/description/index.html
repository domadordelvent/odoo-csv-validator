Odoo CSV Validator 2.0

Validate CSV structure and configurable column rules before importing into Odoo 18 Community.

  • Strict UTF-8 and Windows-1252 decoding.
  • Empty and duplicate headers, column counts, Python CSV parser errors and NUL detection.
  • Physical line numbers, record counts and downloadable CSV reports.
  • Read-only analysis: the source file is never modified.
  • Private reusable validation profiles: required, unique, integer, decimal and inclusive minimum rules.
  • Configure columns with standard Odoo forms; no code required.

Maximum upload: 10 MiB. Maximum columns per record: 1,000. Maximum header: 64 KiB. Maximum data records: 100,000. Detailed reports contain up to 1,000 issues and indicate truncation or incomplete analysis.

Structural validation does not verify Odoo field values or perform imports. Uploads and reports are stored temporarily in Odoo.
